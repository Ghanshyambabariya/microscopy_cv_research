# Project Portfolio Index

This folder organizes the repository into five readable portfolio projects. The source code remains shared under `src/`, configs remain in `configs/`, and generated benchmark artifacts remain in `reports/`, but each project folder gives a clean story and copied result snapshots for fast review.

| Folder | Project | Primary Audience |
|---|---|---|
| `01_microscopy_cv` | Microscopy CV Research | computer vision, microscopy, research labs |
| `02_process_signal_ml` | Materials Process Signal ML | manufacturing analytics, signal processing |
| `03_tool_wear_benchmarks` | Real Tool-Wear Benchmarks | predictive maintenance, process monitoring |
| `04_materials_property_ml` | Materials Property ML | materials informatics, property prediction |
| `05_multimodal_platform` | Multimodal Materials AI Platform | ML engineering, portfolio overview |

## How To Review

Start with the root `README.md`, then open any project folder based on the role:

- CV or microscopy role: `01_microscopy_cv`
- manufacturing/process role: `02_process_signal_ml` and `03_tool_wear_benchmarks`
- materials informatics role: `04_materials_property_ml`
- broad AI/ML role: `05_multimodal_platform`
