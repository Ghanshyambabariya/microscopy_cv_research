# MicroForge AI Projects

[Back to main README](../README.md)

This folder keeps the larger repository readable. The shared implementation remains in `src/`, `scripts/`, `configs/`, and `reports/`; each project folder below gives a short summary and copied result snapshots.

## Project Folders

| Folder | Project | Main Use | Main Output |
|---|---|---|---|
| [01_microscopy_cv](01_microscopy_cv) | Microscopy CV Research | computer vision, SEM/TEM/EBSD research | segmentation figures, active-learning logs |
| [02_process_signal_ml](02_process_signal_ml) | Materials Process Signal ML | sensor analytics, grinding/process monitoring | 20 kHz signal features and model metrics |
| [03_tool_wear_benchmarks](03_tool_wear_benchmarks) | Real Tool-Wear Benchmarks | predictive maintenance, machining AI | real-data wear regression/classification |
| [04_materials_property_ml](04_materials_property_ml) | Materials Property ML | materials informatics | property regression report |
| [05_multimodal_platform](05_multimodal_platform) | Multimodal Materials AI Platform | combined benchmark automation | unified leaderboard and platform report |

## How I Use These Folders

1. Start with [05_multimodal_platform](05_multimodal_platform) for the complete picture.
2. Use [01_microscopy_cv](01_microscopy_cv) for microscopy and segmentation experiments.
3. Use [03_tool_wear_benchmarks](03_tool_wear_benchmarks) for real machining datasets.
4. Use [04_materials_property_ml](04_materials_property_ml) for structure/property regression.
